## Coding Language and Syntax
1. const — Declare a constant variable, const creates a variable that cannot be reassigned.
Basic syntax:
const variableName = value;
const name = "John";           // String
const age = 25;                // Number
const isActive = true;         // Boolean
const user = { name: "John" }; // Object
const numbers = [1, 2, 3];     // Array
- Must be assigned when declared
- Cannot be reassigned (unlike let)
- Block-scoped (only exists within {})

e.g.
```javascript
const geistSans = Geist({
  variable: "--font-geist-sans",
  subsets: ["latin"],
});
```
- Creates a variable named geistSans
- Stores the result of calling Geist()
- Cannot be reassigned later

2. function — Define reusable code
A function is a block of code that runs when called.
Basic syntax:
```js
function functionName(parameters) {
  // code to execute
  return result;
}
```
Function types:
```js
// 1. Regular function:
function greet(name) {
  return "Hello, " + name;
}

// 2. Arrow function (alternative):
const greet = (name) => {
  return "Hello, " + name;
};

// 3. Function with no parameters:
function sayHello() {
  return "Hello!";
}

// 4. Function with multiple parameters:
function add(a, b) {
  return a + b;
}

// Line 29 in layout.tsx
// Function name: RootLayout
// Takes children as a parameter
// Returns JSX
export default function RootLayout({ children }) {
  return (
    <html lang="en">
      <body>{children}</body>
    </html>
  );
}
```

3. export — Share code between files
Basic syntax:
```js
// Named export:
export const myVariable = "value";
export function myFunction() { }

// Default export:
export default function MyComponent() { }
// OR
export default myVariable;

// Import examples:
// Import default export
import RootLayout from './layout';

// Import named export
import { metadata } from './layout';

// Import both
import RootLayout, { metadata } from './layout';

// Import with different name
import { metadata as pageMetadata } from './layout';
```

Default export
- Only one per file
- Can be imported with any name
- No curly braces {} when importing
- Common for main component/functio in a file

Named expoert
- Multiple per file
- Must use the exact experted anme with importing
- Requires ucrly braces {} when importing
- Common for utilities, constants. multiple exports


```tsx
1. Named export:
// Line 17 in layout.tsx
export const metadata = {
  title: "Create Next App",
  description: "Generated by create next app",
};
- Exported as metadata
- Imported elsewhere as: import { metadata } from './layout'

2. Default export:
// Line 29 in layout.tsx
export default function RootLayout({ children }) {
  // ...
}
// Exported as the default
// Imported elsewhere as: import RootLayout from './layout' (or any name)
```

# Server vs Client (important in Next.js)
-  By default, components are Server Components.
If you need:
- useState
- useEffect
- mic / audio / browser APIs

You MUST add: "use client" at the top of the file.

```tsx
export default function Page() {
  const [x, setX] = useState(0)

  useEffect(() => {
    console.log("mounted")
  }, [])

  return <div>{x}</div>
}

```
